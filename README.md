# ポテト焼きオンライン

オンライン協力バカゲー - 全員で巨大なポテトを焼こう！

## 概要

「ポテト焼きオンライン」は最大10人で同時にプレイできるオンライン協力バカゲーです。プレイヤー全員が協力して（あるいは邪魔して）、巨大なポテトを完璧に焼き上げることを目指します。

## ゲームの特徴

- **最大10人同時プレイ**: 友達と一緒にポテトを焼こう
- **リアルタイム同期**: 全プレイヤーの操作が即座に反映
- **多彩なアクション**: 火力調整、調味料、特殊武器など13種類のアクション
- **ランダムイベント**: カラス、猫、UFO、ブラックホールなど予測不能なイベント
- **バカ演出**: 火力100%で家→街→地球→銀河→宇宙が燃える演出
- **実績システム**: 100種類以上の実績を解除
- **オンラインランキング**: 世界のプレイヤーと競おう
- **PWA対応**: スマホ・PCでどこでもプレイ可能

## システム要件

- Node.js 18.0以上
- npm 9.0以上
- 最新のブラウザ（Chrome、Firefox、Safari、Edge）

## インストール手順

1. リポジトリをクローン
```bash
git clone <repository-url>
cd potato-bake-online
```

2. 依存パッケージをインストール
```bash
npm install
```

## 起動方法

### 開発モード

クライアントとサーバーを同時に起動：

```bash
# ターミナル1: サーバー起動
npm start

# ターミナル2: クライアント起動
npm run dev
```

ブラウザで `http://localhost:3000` にアクセス

### 本番ビルド

```bash

npm run build

# サーバー起動
```

## ゲームルール

### 基本ルール

1. ルームを作成または参加する
2. 全員がReady状態になるとゲーム開始
3. 制限時間180秒以内にポテトを焼く
4. 全員が自由にアクションを使用可能

### クリア条件

制限時間終了時の焼き加減：
- **Perfect**: 全員勝利
- **Good**: 勝利
- **焦げ**: 敗北
- **生**: 敗北
- **爆発**: 敗北

### アクション一覧

| アクション | 効果 |
|-----------|------|
| 🔥 火力UP | 火力+10% |
| ❄️ 火力DOWN | 火力-10% |
| 🫒 油 | 温度+5°C |
| 🧂 塩 | 焼き加減+2% |
| 🧈 バター | 温度+3°C、焼き加減+1% |
| 🧊 氷 | 温度-15°C |
| 💨 送風 | 火力-5% |
| 💧 水 | 温度-20°C、火力-20% |
| 📦 電子レンジ | 温度+30°C、焼き加減+5% |
| 🔫 火炎放射器 | 火力+30%、温度+20°C |
| 🌀 扇風機 | 火力-15% |
| 🔦 宇宙レーザー | 温度+50°C、HP-10 |
| 🕳️ ブラックホール | HP-20、温度-30°C |

### ランダムイベント

数秒ごとにランダムでイベント発生：
- 🐦 カラス来襲 - 焼き加減-5%
- 🐱 猫が奪う - 温度-10°C
- 🛸 UFO誘拐 - 温度-20°C
- 🌧️ 巨大雨 - 温度-15°C、火力-10%
- 🌋 火山噴火 - 火力+30%
- 💡 停電 - 火力0%
- ⛽ ガス切れ - 火力0%
- 🕳️ ブラックホール - HP-10、温度-30°C
- ☄️ 隕石 - HP-15、温度+50°C
- 🥔 巨大ポテト - HP+20
- 🔥 焼き網落下 - 火力0%、温度-30°C

## バカ演出（火力100%時）

火力が100%に達すると、以下の演出が連続で発生：

1. コンロ巨大化
2. 家燃える
3. 街燃える
4. 地球燃える
5. 銀河燃える
6. 宇宙崩壊
7. 最後に「まだ芯が冷たい。」と表示

## 実績

100種類以上の実績があります：

### 基本実績
- 初めてのポテト - 初めてゲームをプレイ
- パーフェクト - 初めてPerfectを達成
- 焦がしちゃった - 初めてポテトを焦がす
- まだ生 - 時間切れで生のまま
- 爆発 - 初めてポテトを爆発させる

### 回数実績
- 完璧主義者 - Perfectを10回達成
- ポテトマスター - Perfectを50回達成
- 伝説のシェフ - Perfectを100回達成

### 特殊実績
- 世界を燃やした - 火力100%到達
- 銀河を燃やした - 銀河崩壊演出を見る
- ブラックホール誕生 - ブラックホールイベント発生

...他100種類以上

## ランキング

オンラインランキングで世界中のプレイヤーと競えます：

- Perfect数ランキング
- 爆発数ランキング
- 焦げ数ランキング
- 総プレイ時間ランキング

## セーブ機能

以下のデータは自動保存されます：

- プレイヤー名
- 実績
- 統計データ（総プレイ数、Perfect数など）
- 設定（音量、画質、言語）
