# 音声ファイル

このフォルダにはBGMと効果音（SE）を配置してください。

## BGM
- menu.mp3 - メインメニュー用BGM
- lobby.mp3 - ロビー用BGM
- game.mp3 - ゲーム中BGM
- result.mp3 - 結果画面用BGM

## 効果音（SE）
- button.mp3 - ボタンクリック
- ready.mp3 - Ready時
- start.mp3 - ゲーム開始
- action.mp3 - アクション実行
- heatUp.mp3 - 火力UP
- heatDown.mp3 - 火力DOWN
- perfect.mp3 - Perfect達成
- explosion.mp3 - 爆発
- event.mp3 - イベント発生
- achievement.mp3 - 実績解除

開発中はWeb Audio APIによるシンセサイザー音が使用されます。
